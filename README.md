# React + TypeScript + Vite — Frontend Sandbox

Este repositório é o **ambiente sandbox de frontend do AccessForge**, destinado ao estudo, à experimentação e à validação prática de conceitos de React, TypeScript e Vite.

O objetivo é desenvolver competências de frontend de forma incremental, por meio de exercícios, protótipos e experimentos isolados, antes de aplicar os conhecimentos à interface definitiva do projeto.

## Objetivos

- Estudar os fundamentos do React, incluindo componentes, JSX, props e composição.
- Praticar TypeScript em componentes e funções.
- Compreender a estrutura de um projeto Vite e seu fluxo de desenvolvimento e build.
- Experimentar requisições HTTP, variáveis de ambiente, estados de interface e tratamento de erros.
- Validar conceitos de integração entre frontend e backend.
- Manter os experimentos de frontend separados da implementação principal do backend.

## Escopo do repositório

Este repositório é exclusivamente um **ambiente de aprendizado e experimentação de frontend**.

Não representa a interface oficial de produção do AccessForge e não substitui o backend principal. Componentes, páginas e implementações desenvolvidos aqui poderão ser descartados, refatorados ou reaproveitados posteriormente, conforme a evolução do projeto.

## Stack

- **React** — construção de interfaces por componentes.
- **TypeScript** — tipagem estática e verificação de tipos.
- **Vite** — servidor de desenvolvimento e ferramenta de build.
- **ESLint** — análise estática e padronização do código.

## Requisitos

- Node.js compatível com a versão do Vite utilizada.
- npm.

## Executar localmente

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Verifique a compilação de produção:

```bash
npm run build
```

Execute a análise estática:

```bash
npm run lint
```

## Organização dos estudos

O desenvolvimento será incremental. Cada etapa deverá consolidar os conceitos estudados antes da introdução de novas funcionalidades.

As implementações podem incluir exercícios isolados, componentes temporários, testes de comportamento e experimentos de integração com o backend. O código deste sandbox não deve ser considerado automaticamente pronto para produção.
